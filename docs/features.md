# Features

> Source code is private/client-confidential. Architecture and implementation details are shared at a safe case-study level.

## Verified Feature Areas

- Storefront catalog for handbags, makeup, accessories, and gift sets
- Product variants and option persistence
- Cart, checkout, confirmation, and phone-protected tracking
- Cash-on-delivery order flow
- Admin dashboard for products, inventory, orders, delivery rules, support settings, and status updates
- USD/LBP presentation
- Arabic/English and RTL-oriented interface expectations
- WhatsApp/support contact surfaces
- SEO metadata, sitemap, robots, JSON-LD, and policy/contact/FAQ page structure
- Production deployment preparation and smoke-test documentation

## Inventory Lifecycle

Local project documentation describes checkout stock reservation, delivered-order sold units, cancellation/failed/returned release behavior, and safeguards against unsafe status transitions that could create invalid inventory state.

## Public-Safe Limits

This repository does not include private application source, production credentials, real customer orders, owner-only documents, payment details, or unpublished client data.
